Quality Checklist

✓
The task is a single, clear instruction.
✓
The output format is specified (length, structure, tone).
Context includes audience and intent.
Constraints list what to avoid, not just what to do.
Variables are named meaningfully and used consistently.
An example of ideal output is included where possible.
The prompt has been tested on at least two platforms.
✨

Prompt Patterns

Role + Task
Set a persona, then give a single clear task.
You are a strict code reviewer. Review the function below for edge cases.
Chain-of-thought
Ask the model to reason step by step before answering.
Think step by step. First list assumptions, then derive the answer.
Few-shot
Show 2-3 examples so the model imitates the shape you want.
Input: apple -> Output: fruit. Input: carrot -> Output: vegetable. Input: banana ->
Structured output
Demand JSON/markdown so results are parseable.
Return strict JSON: { "title": string, "score": number }
Self-critique
Ask the model to critique & revise its own draft.
Write the answer, then list 3 weaknesses, then rewrite.
Negative prompting
State what NOT to include.
...minimal, clean. Avoid: text, watermarks, extra fingers.

Pro Tips

✓
Start broad, narrow fast - First prompt gets you a draft; 2-3 refinements beat one "perfect" prompt.
✓
Show, don't just tell - One example is worth three adjectives. Few-shot wins on tone.
✓
Separate instructions from content - Use clear delimiters (---, ```). Models follow structure.
✓
Name the failure mode - Tell it what NOT to do. "Avoid cliches." "No bullet points."
✓
Version your prompts - Save what works. Track the change + the output improvement.
✓
Temperature matters - Lower for code/JSON, higher for creative. If the app lets you set it.
⚖

Platform Differences

The same prompt rarely performs the same across platforms. Start with a text-first phrasing, then tune per platform.

Platform Best at How to prompt
ChatGPT Reasoning, long-form, code Use system role + step-by-step tasks.
Gemini Multimodal, web-aware Give explicit sources and formats.
Grok Conversational, current events Add tone cues; tolerates casual prompts.
Midjourney Stylized imagery, aesthetics Use commas; end with --ar and --s.
Firefly Brand-safe, commercial Short descriptive phrases beat paragraphs.
FLUX Photoreal, fine control Natural language, specify lens + lighting.
